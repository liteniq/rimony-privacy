2. 외부 서비스와 자동 처리 정보

리모니는 Google Mobile Ads SDK와 User Messaging Platform(UMP) SDK를 포함합니다. 현재 앱은 Google 테스트 광고만 요청하며 실제 수익 광고는 요청하지 않습니다. 앱을 시작하면 UMP에서 광고 동의 상태를 확인하고, 광고를 요청할 수 있다는 결과가 나온 경우에만 Google Mobile Ads SDK를 초기화합니다. 현재 광고 요청에는 Google의 테스트 배너 ID만 사용하며 정기결제 목록, 사용자가 입력한 금액·메모, 문자 원문과 캡처 이미지를 광고 요청값으로 넣는 코드는 없습니다.

Android용 Google Mobile Ads SDK 데이터 공개에 따르면, 이 SDK는 광고 제공, 분석과 부정행위 방지를 위해 IP 주소, 앱 실행·탭·동영상 조회 같은 앱 상호작용, 앱·SDK 성능에 관한 진단 정보, Android 광고 ID·앱 세트 ID와 해당되는 계정 관련 식별자를 자동으로 수집하고 공유합니다. Google LLC 및 관련 계열사는 SDK 기능 이용과 SDK 요청 과정에서 이 정보를 처리할 수 있으며, 정보는 암호화되어 전송되고 해외 서버(미국 등을 포함)에서 처리될 수 있습니다. 이는 특정 한 국가나 특정 수신자만으로 한정되지 않습니다. 정보의 보유 기간은 정보 유형과 처리 목적에 따라 다르며, 자세한 내용은 Google 보유 정책과 Google 개인정보처리방침 및 문의 안내에서 확인할 수 있습니다. 실제 수익 광고를 사용하기 전에는 광고 유형과 계정 설정을 다시 확인하고 이 방침을 먼저 갱신합니다.

스크린샷의 글자 인식에는 기기에 포함된 ML Kit 한국어 텍스트 인식 모델을 사용합니다. ML Kit Android 데이터 공개에 따르면 ML Kit는 진단과 사용 분석을 위해 기기 제조사·모델·운영체제·빌드와 ML 가속기 정보, 앱 패키지명·버전, 설치 단위 식별자, 지연 시간 등 성능 정보, 이미지 형식·해상도 같은 API 구성, 입력·출력 크기, 기능 버전, 초기화·감지·리소스 해제 이벤트와 오류 코드를 수집할 수 있습니다. Google은 해당 안내에 열거된 정보를 HTTPS로 암호화하며 제3자에게 이전하지 않는다고 밝히고 있습니다. 이미지 내용과 인식된 문자열 자체는 이 공식 안내의 자동 수집 항목에 열거되어 있지 않습니다. ML Kit Android 텍스트 인식 안내도 함께 확인할 수 있습니다.
